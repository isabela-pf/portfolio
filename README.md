## Setup

1. Install `uv` and local packages
    
    ```shell
    curl -LsSf https://astral.sh/uv/install.sh | sh && uv venv && uv sync
    ```

2. Run the local dev server on [localhost:8000](http://localhost:8000)

    ```shell
    uv run mkdocs serve --dev-addr=127.0.0.1:8000
    ```
